# What to drive

One file for each part of the game an agent can prove by itself. Each says how a player reaches the feature, the exact commands, and what state proves it.

| File | Covers |
|---|---|
| `rules.md` | Anything the rules decide: farming, crafting, building, quests, pets. No browser. |
| `browser.md` | The game in Chrome: moving, talking, the menus, what is drawn |
| `build-mode.md` | Build mode: drag to till, plant and fence, undo |
| `fight-lab.md` | The fight lab behind `?scene=fight`: three ways to fight, the bot and real keys, the ratings log |
| `account.md` | Sign-in, backing up and restoring a world, the world list |
| `world-server.md` | Joining a world, seeing another player, the save |

Not covered yet: sound (nobody can hear it here; check the request and the decode), the opening film, and other players drawn in the game (the browser does not connect to the world server yet).
